## 🚀 Como Usar

1. Abra o arquivo `cronograma-estudos-corrigido.html` no navegador
2. Seus dados serão salvos automaticamente no navegador
3. Você pode limpar os dados indo no Console do navegador e digitando:
   ```javascript
   localStorage.clear();
   location.reload();
   ```
